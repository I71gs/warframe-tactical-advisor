Frequently Asked Questions

Got questions? We have compiled solutions for setting up accounts, layouts, and configurations.

Q: How do I switch accounts?

Open the Settings tab, select Alt Account from the Account Profile dropdown, and click Save Settings. This dispatches the switch account bus signals, resetting active data cache variables and reloading the UI instantly.

Q: Does the application save login credentials?

No. The advisor operates entirely offline using a local SQLite database file `player.db` to save mastery ranks and upgrade lists. It doesn't ask for or store your Warframe game credentials.

Q: How do I add custom dashboards or features?

Check out the Extensible Plugin SDK. You can author custom Python classes that inherit from `PluginBase` and register them on application launch.
