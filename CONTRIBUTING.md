# Contributing to Warframe Tactical Advisor

We welcome contributions from the Warframe and open source communities! Here is how you can help:

## Code Contributions
1. Fork the repository.
2. Create a new feature branch (`git checkout -b feature/my-new-feature`).
3. Set up linting and formatting locally with `ruff` and `black`.
4. Add comprehensive unit tests under the `tests/` directory for any new logic.
5. Run the test suite: `pytest` to confirm all checks pass.
6. Commit your changes and push to your fork.
7. Submit a Pull Request.
